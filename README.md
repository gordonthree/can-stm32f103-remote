This project supports a few different STM32 micros. I should rename it, since I quickly hit a wall on the F103 being rather small and slow compared to newer chips.

Supported micros:
* STM32L432K
* STM32F303K
* STM32F103C6T6 "Blue Pill"

Not an ST product but the ARM code is close enough to fit in this particular project
* Teensy 3.1
